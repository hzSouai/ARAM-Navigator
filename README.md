# LOL 大乱斗助手

大乱斗 / 海克斯大乱斗备选席自动换人工具，基于英雄联盟客户端本地 **LCU API**。
带一个本地网页控制台，日常使用不用盯着黑框喵。

它只读取客户端自己的选人会话，不读游戏内存、不注入游戏进程。用官方接口把备选席上的
英雄换到你手上，并且**每次换完都会回读会话确认**；如果客户端没有真正落地，会自动重试。

## 为什么不用 winer 的自动换人

winer 的自动换人在某些情况下会「请求返回成功，但客户端没有真正换过去」。这个工具针对
这个问题做了四件事：

1. 等选人阶段进入 `BAN_PICK` / `FINALIZATION`，并且状态稳定若干次轮询后才出手；
2. 必须等自己已经分到初始英雄（`championId > 0`）才换，避免初始分配把换人结果覆盖掉；
3. 换人后回读 `/lol-champ-select/v1/session`，确认自己手上的英雄真的变了；
4. 没落地就按配置重试，并记录完整日志。

## 网页控制台

启动后会打开 `http://127.0.0.1:8765/`，包含：

- **当前英雄 / 备选席**：实时显示阶段、手上英雄、剩余时间；点备选席英雄可以手动秒换；
  心愿英雄会金色高亮并显示优先级编号；不在备选席里的二选一候选会出现在「待选」条里。
- **好友房间**：列出在线好友和他们的状态；好友在可加入的房间里时，点「加入」直接进房。
- **我的状态 / 离开房间**：显示在线状态和个性签名；在房间/匹配/准备阶段可以一键离开房间。
- **设置弹窗**（右上角「⚙ 设置」）：心愿英雄拖动排序/上下移动/删除/搜索添加（最多 20 个，
  改动自动保存）、启动延迟、稳定轮询次数、最少剩余时间、重试次数、自动接受/返回延迟、
  自动返回房间、自动接受对局、待选界面出现心愿英雄自动选、海克斯爆发抢英雄、练习模式；
  底部还有打开日志目录、导出当前会话。
- **运行日志**：实时滚动，按级别着色。
- **暂停 / 恢复**、**打开日志目录**、**右上角退出**。

页面只监听本机 `127.0.0.1`，不会暴露到局域网。

## 加入好友房间

网页里的 **好友房间** 卡片会读取 `/lol-chat/v1/friends`，把在线好友按状态列出来：

- 好友在可加入的房间（`outOfGame` / `hosting_*` / `inQueue`）时，显示「加入」按钮；
- 派对 ID 从好友的 `lol.pty`（或 `lol.lobbyId`）里取，点击后调用
  `POST /lol-lobby/v2/party/{partyId}/join`；
- 好友在游戏中、选人中、观战中，或房间已满/已关闭时，客户端会拒绝，网页会把错误提示出来；
- 列表每 15 秒自动刷新，也可以点「刷新」立即拉取。

这是你主动点击才执行的操作，不会自动帮你进别人的房间喵。

## 离开房间与我的状态

- **离开房间**：在房间/匹配中/准备确认阶段，好友房间卡片右上角会显示「离开房间」按钮。
  后端调用 `DELETE /lol-lobby/v2/lobby`；匹配中会先取消搜索，准备确认会先拒绝，
  然后离开。房主离开可能导致队伍解散，网页会先确认。
- **我的状态**：每 5 秒读取 `GET /lol-chat/v1/me`，显示在线 / 离开 / 勿扰 / 手机在线 /
  离线，以及你的个性签名。状态变化会在网页上自动刷新。

## 待选界面自动选

客户端显示「选择你的英雄」和两张卡的那个界面，底层数据仍然是 LCU 选人会话：

- 一张是当前英雄（`myTeam[localPlayerCellId].championId`），另一张通常来自备选席
  （`benchChampions`）；有些二选一界面还会出现**不在备选席里的候选**，网页会尽量从
  `championPickIntent`、本地 `pick` action 和 `isPriority` 备选里提取，显示在「待选」条；
- 心愿英雄出现在备选席/待选卡里，并且优先级比当前英雄更靠前时，会自动换过去；
- 在 `FINALIZATION` 阶段如果客户端还没给你当前英雄（`championId=0`），
  「待选界面出现心愿英雄自动选」也允许直接从心愿列表里选一个；
- 如果两张卡都不在心愿列表里，就不会自动选，把它们加进心愿列表即可；
- 关掉这个开关后，`BAN_PICK` 阶段的普通自动换人仍然生效，只有 `FINALIZATION`
  的待选自动选会停。

## 选人计时器

- 海克斯大乱斗（2400）的 `BAN_PICK` 总时长 15 秒，`FINALIZATION` 30 秒；
- 网页在 BAN_PICK 显示 **「距可换人约 X 秒」**，FINALIZATION 显示 **「可换人剩余 X 秒」**；
- 日志会在进入 BAN_PICK 时报剩余秒数，并在剩 5 秒 / 1 秒时提醒；
- **海克斯爆发抢英雄**（默认开启）：剩 1 秒时开始预发；进入 FINALIZATION 后前 3 秒约每
  300ms 请求一次；3～5 秒放缓到约每 800ms 一次；5 秒后停止喵；
- 关掉爆发模式后，回到「等 FINALIZATION 第一次轮询出手 + 12 次重试」的普通策略喵。

## 自动返回房间与自动接受对局

- **自动返回房间**：客户端进入 `WaitingForStats` / `PreEndOfGame` / `EndOfGame` 后会等 3 秒，
  再调 `POST /lol-lobby/v2/play-again`。会先尝试在荣誉界面提前返回；客户端拒绝就在
  `EndOfGame` 再试。等完 3 秒会重新确认还在结算流程里；你手动离开就取消。
  日志会记录 `gameflow: ... -> ...` 阶段变化和每次请求的结果。
- **自动接受对局（准备）**：进入准备确认阶段后读取 `ready-check`；如果还是
  `InProgress` 且你还没回应，等 1.5 秒再确认一次，然后调
  `POST /lol-matchmaking/v1/ready-check/accept`。你手动接受/拒绝都不会被覆盖。
- 两个开关默认开启，网页右上角「⚙ 设置」里可以单独关掉；自动接受/返回延迟也可以
  直接在设置弹窗里调整。
- 这里没有加「自动开始匹配」（房主点开始）——那是另一个接口，需要的话可以再补。

## 快速开始

1. 确认已安装 **Node.js 20+**（`node --version`）。
2. 正常登录英雄联盟客户端。
3. 双击 **`launch-web.vbs`**（桌面上的 `启动LOL大乱斗助手.vbs` 也可以）。
4. 浏览器会自动打开 `http://127.0.0.1:8765/`；Node 进程在后台隐藏运行，没有黑框。
5. 如果 winer 还开着，去它的 **自动化 → 备选席** 把「自动换心愿英雄」关掉，避免两边抢请求；
   winer 的「客户端里秒换」可以保留，它只在你手动点击时生效。

之后正常开大乱斗/海克斯大乱斗即可。网页会自动显示选人状态和换人结果。

> 如果端口 8765 已经被上一个实例占用，新实例会退出；直接打开已有页面即可。
> 想重启：先点网页右上角的「退出」，再双击启动器。

## 控制台模式（调试用）

`start-console.bat` 会以管理员身份打开黑框控制台，适合排查问题。其他调试命令建议在
管理员终端里运行：

```bat
node src\index.js --probe            :: 打印当前选人会话
node src\index.js --list-champions   :: 列出客户端里的英雄 ID 和名字
node src\index.js --dry-run          :: 控制台练习模式
node src\index.js --help             :: 帮助
```

## 配置 `config.json`

网页里的改动会直接写回这个文件；也可以手动编辑后重启。

| 字段 | 说明 |
|---|---|
| `wishlist` | 心愿英雄 ID 数组，**越靠前优先级越高** |
| `clientDir` | LeagueClient 目录；找不到客户端时改这里 |
| `startupDelayMs` | 进入选人后至少等多少毫秒才出手（默认 2500） |
| `stablePolls` | 状态连续稳定多少次轮询才出手（默认 4，约 1.2 秒） |
| `allowedPhases` | 普通大乱斗允许出手的阶段（默认 `BAN_PICK` / `FINALIZATION`）；海克斯大乱斗 2400 会强制等到 `FINALIZATION` |
| `minTimeLeftMs` | 阶段剩余时间低于此值时不再出手（默认 1000） |
| `pollMs` | 轮询间隔（默认 300ms） |
| `verifyDelayMs` | 换人后等多久回读确认（默认 350ms） |
| `retryDelayMs` | 两次尝试之间的最小间隔（默认 600ms） |
| `maxRetries` | 同一个英雄最多尝试几次（默认 12，覆盖备选席冷却窗口） |
| `maxSwapsPerGame` | 单局最多发几次换人请求（默认 24） |
| `dryRun` | 练习模式：只演练换英雄（含爆发），不实际发送 swap；自动接受/返回仍按开关执行 |
| `webPort` | 本地网页端口（默认 8765） |
| `autoPlayAgain` | 对局结束后自动返回房间（默认 `true`） |
| `autoAccept` | 准备确认阶段自动接受（默认 `true`） |
| `autoSelectCandidate` | 待选/确认界面出现心愿英雄时自动选（默认 `true`） |
| `benchBurstMode` | 海克斯大乱斗爆发抢英雄（默认 `true`，-1s 预发，3s 高频，5s 停止） |
| `acceptDelayMs` | 自动接受前等待（默认 1500ms） |
| `playAgainDelayMs` | 自动返回房间前等待（默认 3000ms） |

## 和 winer 同时使用

- 请把 winer 的 **自动化 → 备选席 → 自动换心愿英雄** 关掉，避免两个程序同时发换人请求。
- winer 的 **客户端里秒换备选席英雄** 可以保留：它只在你手动点击时生效。
- 网页控制台顶部会显示连接状态和当前模式；日志里也会提示 winer 是否还开着自动换人。

## 日志

- 网页：**运行日志** 卡片实时显示，点「日志」按钮打开日志目录。
- 文件：`logs/helper-YYYY-MM-DD.log`。
- 详细选人时间线：`logs/timeline-YYYY-MM-DD.log`，选人阶段约每 300ms 一行，记录
  `phase / left / held / pickIntent / bench / candidates / trades / 本地 actions`；
  用来排查「二选一 → 换英雄」的真实顺序和字段。
- 原始快照：`logs/sessions/session-*.json`，选人状态变化时自动保存（每局最多 60 份），
  包含完整的 LCU 选人会话；也可以在设置里点「导出当前会话」手动保存。快照只存在本机，
  排查完可删除。
- 日志会记录阶段、手上的英雄、备选席、换人请求、回读结果和重试原因。

## 故障排查

**网页打不开 / 一直显示未连接**

- 确认 Node 进程在运行；双击启动器后等 2 秒再刷新页面。
- 端口被占用时先退出旧实例；或者改 `config.json` 的 `webPort` 后重启。
- 客户端没登录时页面会显示「未连接」，登录后会自动重连。

**提示找不到客户端 / 读不到命令行**

- 确认客户端已经登录。
- 启动器会以管理员身份运行 Node（国服客户端由 WeGame 以管理员身份启动，普通权限读不到
  客户端命令行）。
- 如果客户端装在别的盘，改 `config.json` 的 `clientDir`。

**一直显示「当前不在选人阶段」**

- 只在选人阶段有会话；游戏内和客户端主页显示这个是正常的。
- 控制台模式跑 `node src\index.js --probe` 可以看当前会话和阶段。

**换了但没落地**

- 日志里会显示 `[WARN] 没有落地`，然后自动重试。
- 如果同一英雄重试 12 次仍失败，工具会暂时放弃；重新进一次选人会重置。
- 目标从备选席消失时，日志会写「可能被队友拿走，停止重试」。
- **海克斯大乱斗（queue 2400）在 `BAN_PICK` 阶段备选席是锁定的**：`bench/swap` 会返回
  `204` 但不执行。工具会自动等到 `FINALIZATION` 所有人选完再出手，不会提前把重试次数用完。
- 普通大乱斗可以适当调大 `startupDelayMs` / `stablePolls`。

## 风险提示

这是第三方工具，使用客户端本地 LCU 接口，不读内存、不修改游戏文件，但**不是 Riot/腾讯
官方支持的产品**。自动换人属于客户端自动化，国服 ACE 会扫盘，理论上存在账号处罚风险；
请自行评估，建议先用小号测试。
