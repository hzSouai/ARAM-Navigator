# ARAM Navigator

英雄联盟大乱斗 / 海克斯大乱斗备选席自动换人工具，基于英雄联盟客户端本地 **LCU API**，
提供本地 Web 控制台。

本项目只读取客户端自身的选人会话，不读取游戏内存，也不注入游戏进程。换人请求发出后会
回读 `/lol-champ-select/v1/session` 校验结果；如果客户端没有实际生效，会按配置重试并
记录完整日志。

## 功能概览

- **备选席自动换人**：按心愿英雄优先级自动换到备选席上的目标英雄；换人后回读校验，
  未生效自动重试。
- **海克斯大乱斗抢英雄**：针对海克斯大乱斗队列的选人时间线优化，在可操作阶段高频尝试。
  队列 ID 默认 2400，连接客户端后会自动识别当前活动队列。
- **三选一网页代点**：客户端出现「选择你的英雄」三张卡时，网页同步显示三张卡；可在网页
  点击选择，或在出现心愿英雄时自动代选，无需操作客户端。
- **自动返回房间 / 自动接受对局**：对局结束后自动回到房间；准备确认阶段自动接受。
- **好友房间**：查看在线好友及状态、加入好友房间、离开房间。
- **房间与匹配**：一键创建海克斯大乱斗房间；房主可在网页直接开始匹配。
- **本地日志**：实时运行日志、选人时间线、原始会话快照，便于排查。
- **桌面启动器**：自带 Windows 启动器，后台启动 Node 服务并自动打开浏览器。

## 环境要求

- Windows 10 / 11；
- Node.js 20 或更高版本；
- 英雄联盟国服客户端，并已正常登录；
- 「三选一网页代点」功能需要客户端本地脚本加载器（可选，仅该功能依赖）。

## 快速开始

1. 安装 Node.js 20+，在终端确认 `node --version` 可用。
2. 启动并登录英雄联盟客户端。
3. 双击项目根目录的 **`ARAM-Navigator.exe`**，或桌面上的「LOL大乱斗助手」快捷方式。
   启动器会在需要时请求管理员权限，在后台隐藏启动 Node 服务，并在网页就绪后自动打开
   浏览器。如果助手已经在运行，双击只会打开已有页面，不会重复启动进程。
4. 浏览器打开 `http://127.0.0.1:8765/` 即可使用。
5. 如需使用三选一网页代点：将 `client-plugin/index.js` 放入客户端本地脚本加载器的
   插件目录，目录结构为 `plugins/aram-navigator/index.js`，然后完全退出并重新启动客户端。
   网页右上角「运行状态」中的「客户端插件」显示「已连接」即表示脚本已加载。
6. 如果同时使用其他会发送换人请求的客户端工具，请关闭其自动换人功能，避免重复请求。

> 端口 8765 已被占用时，新实例会退出；直接打开已有页面即可。需要重启时，先点击网页
> 右上角的「退出」，再运行启动器。

## 启动器

`ARAM-Navigator.exe` 是 Windows 启动器，不是将 Node 打包进去的独立程序，因此仍需安装
Node.js 20+。

- 从 `config.json` 读取 `webPort`（默认 8765）；
- 如果端口已处于监听状态，只打开浏览器，不启动第二个实例；
- 否则请求管理员权限，隐藏启动 `node src\index.js --web`，最多等待 10 秒后打开页面；
- 仅在需要启动 Node 服务时请求 UAC；服务已在运行时不会弹出权限提示；
- 管理员权限用于读取以管理员身份运行的国服客户端命令行；
- 如果程序目录下存在 `runtime\node.exe`，启动器会优先使用该内置运行时；发布便携版时
  可将 Node 运行时一并打包；
- 源码位于 `src/launcher/Launcher.cs` 和 `src/launcher/app.manifest`；
- 需要重新编译时，运行 `build-launcher.bat`（使用 Windows 自带的 .NET Framework 编译器）；
- `launch-web.vbs` 保留作为备用启动方式。

## 网页控制台

启动后访问 `http://127.0.0.1:8765/`，页面只监听本机回环地址，不会暴露到局域网。

- **选人操作区**：显示当前英雄、阶段剩余时间、待选英雄、队友交易和备选席。点击备选席
  英雄可以手动换人；心愿英雄会高亮并显示优先级编号。
- **三选一面板**：客户端显示三张卡时，面板会同步出现，可点击「选它」由客户端脚本代点。
- **运行状态**：右上角「运行状态」按钮展开详细面板，包含连接状态、客户端脚本、在线状态、
  客户端阶段、房间、模式、队列/对局和最近动作。按钮左侧指示灯：绿色表示客户端与脚本
  均正常，黄色表示客户端已连接但脚本未加载，红色表示客户端未连接。
- **好友房间**：列出在线好友及状态，支持加入好友房间；底部提供「创建海克斯大乱斗房间」
  和「寻找对局」。
- **设置**：心愿英雄排序与搜索添加、轮询与重试参数、自动返回、自动接受、待选自动选择、
  三选一自动代选、海克斯爆发模式、练习模式、打开日志目录、导出当前会话。
- **运行日志**：实时滚动，按级别着色。
- **暂停 / 恢复**：暂停自动换人，手动操作不受影响。
- **退出**：关闭本地助手进程。

## 换人策略与校验

自动换人按以下顺序执行：

1. 等待选人阶段进入 `BAN_PICK` 或 `FINALIZATION`，并要求状态稳定若干次轮询；
2. 等待本地玩家已经获得初始英雄（`championId > 0`），避免初始分配覆盖换人结果；
3. 从备选席中选择心愿列表中优先级最高的目标；
4. 调用 `POST /lol-champ-select/v1/session/bench/swap/{championId}`；
5. 回读选人会话，确认本地玩家的英雄确实已变更；
6. 未生效时按 `retryDelayMs` 重试，直到达到 `maxRetries` 或目标离开备选席。

海克斯大乱斗队列（默认 2400，连接客户端后自动识别）在 `BAN_PICK` 阶段备选席处于锁定
状态，接口可能返回成功但不会实际换人，因此该队列会强制等待到 `FINALIZATION` 再执行。

## 选人时间线与爆发模式

- 海克斯大乱斗的 `BAN_PICK` 总时长约 15 秒，`FINALIZATION` 约 30 秒；
- 网页在 `BAN_PICK` 显示「距可换人约 X 秒」，在 `FINALIZATION` 显示「可换人剩余 X 秒」；
- 开启「海克斯爆发抢英雄」后，在阶段结束前约 1 秒开始预发请求；进入 `FINALIZATION`
  后的前 3 秒约每 300 ms 尝试一次，3 至 5 秒放缓到约每 800 ms 一次，5 秒后停止；
- 关闭爆发模式后，使用「进入 `FINALIZATION` 后首次轮询出手 + 12 次重试」的普通策略。

## 自动返回与自动接受

- **自动返回房间**：客户端进入 `WaitingForStats`、`PreEndOfGame` 或 `EndOfGame` 后等待
  配置的延迟，再调用 `POST /lol-lobby/v2/play-again`。会优先尝试在荣誉界面提前返回；
  客户端拒绝时在 `EndOfGame` 再次尝试。等待期间会重新确认仍在结算流程中，用户手动离开
  则取消。
- **自动接受对局**：进入准备确认阶段后读取 `/lol-matchmaking/v1/ready-check`；若仍处于
  `InProgress` 且用户尚未回应，等待配置的延迟后再次确认并调用
  `POST /lol-matchmaking/v1/ready-check/accept`。用户手动接受或拒绝不会被覆盖。
- 两项功能默认开启，可在设置中分别关闭并调整延迟。

## 客户端三选一网页代点

客户端最后的「选择你的英雄」三张卡由客户端本地渲染，在用户手动选择前不会出现在 LCU
选人会话中，只能看到备选席。为此项目附带一个轻量客户端脚本 `client-plugin/index.js`：

- 脚本读取客户端页面中「选择你的英雄」标题下的三张卡名称，并上报到本机网页；
- 网页显示与客户端一致的三张卡；
- 在网页点击「选它」后，指令进入本机队列，由客户端脚本代为点击对应卡片；
- 默认开启「客户端三选一出现心愿英雄自动选」：三张卡中存在心愿英雄时，自动选择优先级
  最高的一个；关闭后仅保留网页手动点击；
- 脚本仅访问 `127.0.0.1:8765`，不读取游戏内存，不修改客户端文件，也不会选择用户未指定
  的卡片。

安装步骤：

1. 将 `client-plugin/index.js` 放入客户端本地脚本加载器的插件目录，目录结构为
   `plugins/aram-navigator/index.js`；
2. 完全退出并重新启动英雄联盟客户端；
3. 打开网页，在右上角「运行状态」中确认「客户端插件」显示已连接。

三选一界面停留时间较短，建议在网页面板出现后尽快完成选择。若「客户端插件」显示未连接，
请检查脚本目录与客户端是否已重启。

## 好友房间与对局操作

好友列表读取自 `/lol-chat/v1/friends`，每 15 秒自动刷新，也可以手动刷新。

- 好友处于可加入状态（`outOfGame`、`hosting_*`、`inQueue`）时，显示「加入」按钮；
- 加入房间调用 `POST /lol-lobby/v2/party/{partyId}/join`；
- 好友在游戏中、选人中、观战中，或房间已满、已关闭时，客户端会拒绝加入，网页会显示错误；
- **离开房间**：在房间、匹配中或准备确认阶段可用。匹配中会先取消搜索，准备确认会先拒绝，
  再调用 `DELETE /lol-lobby/v2/lobby`。房主离开可能导致队伍解散，网页会先确认；
- **创建海克斯大乱斗房间**：调用 `POST /lol-lobby/v2/lobby`，使用当前识别到的海克斯
  大乱斗队列（默认 2400）；已在房间或游戏中时按钮禁用；
- **寻找对局**：调用 `POST /lol-lobby/v2/lobby/matchmaking/search`；仅当当前房间为
  海克斯大乱斗队列且用户是房主时可用，匹配中按钮禁用。开始匹配前网页会二次确认。

## 配置

网页中的修改会写回 `config.json`，也可以手动编辑后重启服务。

| 字段 | 说明 |
|---|---|
| `wishlist` | 心愿英雄 ID 数组，越靠前优先级越高 |
| `clientDir` | LeagueClient 目录；无法自动发现客户端时修改 |
| `startupDelayMs` | 进入选人后至少等待的毫秒数（默认 2500） |
| `stablePolls` | 状态连续稳定多少次轮询后出手（默认 4） |
| `allowedPhases` | 普通大乱斗允许出手的阶段（默认 `BAN_PICK` / `FINALIZATION`）；海克斯大乱斗队列会强制等待 `FINALIZATION` |
| `minTimeLeftMs` | 阶段剩余时间低于该值时不再出手（默认 1000） |
| `pollMs` | 轮询间隔（默认 300 ms） |
| `verifyDelayMs` | 换人后等待回读确认的毫秒数（默认 350） |
| `retryDelayMs` | 两次尝试之间的最小间隔（默认 600） |
| `maxRetries` | 单个英雄的最大尝试次数（默认 12） |
| `maxSwapsPerGame` | 单局最大换人请求次数（默认 24） |
| `dryRun` | 练习模式：只演练换人，不发送实际请求；自动接受/返回仍按开关执行 |
| `webPort` | 本地网页端口（默认 8765） |
| `autoPlayAgain` | 对局结束后自动返回房间（默认 `true`） |
| `autoAccept` | 准备确认阶段自动接受（默认 `true`） |
| `autoSelectCandidate` | 待选/确认界面出现心愿英雄时自动选择（默认 `true`） |
| `autoPickClientCard` | 客户端三选一出现心愿英雄时自动代选（默认 `true`） |
| `benchBurstMode` | 海克斯大乱斗爆发抢英雄（默认 `true`） |
| `acceptDelayMs` | 自动接受前的等待时间（默认 1500 ms） |
| `playAgainDelayMs` | 自动返回房间前的等待时间（默认 3000 ms） |

## 日志

- 网页「运行日志」实时显示运行日志；
- 文件日志：`logs/helper-YYYY-MM-DD.log`；
- 选人时间线：`logs/timeline-YYYY-MM-DD.log`，选人阶段约每 300 ms 记录
  `phase / left / held / pickIntent / bench / candidates / trades / 本地 actions`；
- 原始快照：`logs/sessions/session-*.json`，选人状态变化时自动保存，每局最多 60 份；
  也可以在设置中导出当前会话。快照仅保存在本机；
- 英雄名缓存：`data/champions.json`，连接客户端后自动更新；客户端未连接时使用本地缓存
  或内置默认名称，避免心愿英雄显示为数字。

## 故障排查

**网页打不开或显示未连接**

- 确认 Node 进程正在运行；启动器启动后等待片刻再刷新；
- 端口被占用时退出旧实例，或修改 `config.json` 的 `webPort` 后重启；
- 客户端未登录时显示未连接，登录后会自动重连。

**无法发现客户端或读取命令行**

- 确认客户端已登录；
- 启动器会以管理员权限启动 Node 服务。国服客户端通常由 WeGame 以管理员身份启动，
  普通权限无法读取客户端命令行；
- 客户端安装在其他盘时，修改 `config.json` 的 `clientDir`。

**心愿英雄显示为数字**

- 客户端未启动或刚断线时，助手会使用 `data/champions.json` 缓存或内置默认名称；
- 连接客户端后会拉取完整英雄名并写回缓存，刷新网页即可。

**一直显示当前不在选人阶段**

- 仅在选人阶段存在选人会话；游戏内和客户端主页显示此信息属正常现象；
- 可使用 `node src\index.js --probe` 查看当前会话和阶段。

**换人请求返回成功但未生效**

- 日志会记录「没有落地」并按配置重试；
- 同一英雄达到最大重试次数后会暂时放弃，重新进入选人会重置；
- 目标从备选席消失时，日志会提示可能被队友选走并停止重试；
- 海克斯大乱斗在 `BAN_PICK` 阶段备选席锁定，工具会自动等待到 `FINALIZATION`；
- 普通大乱斗可以适当提高 `startupDelayMs` 或 `stablePolls`。

**三选一面板不出现**

- 确认 `client-plugin/index.js` 位于客户端本地脚本加载器的插件目录；
- 确认客户端在安装脚本后已完全重启；
- 在网页「运行状态」中检查「客户端插件」是否显示已连接。

**版本更新后海克斯大乱斗队列异常**

- 海克斯大乱斗的队列 ID 可能随版本或活动轮换；助手连接客户端时会读取
  `/lol-game-queues/v1/queues` 自动识别当前活动队列，识别失败时回退到 2400；
- 如果自动识别结果异常，可在日志中搜索「海克斯大乱斗队列」查看实际使用的队列 ID。

## 控制台模式（调试）

`start-console.bat` 会以管理员身份打开控制台，适合排查问题。其他调试命令建议在管理员
终端中执行：

```bat
node src\index.js --probe            :: 打印当前选人会话
node src\index.js --list-champions   :: 列出客户端中的英雄 ID 和名称
node src\index.js --dry-run          :: 控制台练习模式
node src\index.js --help             :: 帮助
```

## 风险提示

本项目是第三方工具，使用客户端本地 LCU 接口，不读取游戏内存，不修改游戏文件，但并非
Riot Games 或腾讯官方支持的产品。自动换人属于客户端自动化操作，国服 ACE 会进行安全
扫描，理论上存在账号处罚风险。请自行评估并在必要时使用小号测试。
